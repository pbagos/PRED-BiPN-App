PRED-BiPN
ToolHelpInfo

Bipartite projection and backbone extraction

Project a two-mode network onto one node set, then keep only its significant edges.

Guide

How to use PRED-BiPN, and what the methods do.

Using the tool

  1. Choose a method. Projections turn a bipartite network (e.g. gene → disease) into a one-mode network of one node set. Backbone extraction keeps only the significant edges of a weighted one-mode network. Use the search box to find a method by name or by what it does; its parameters appear under Run.
  2. Add an edge list. Drop a .txt, .tsv or .csv file, or choose one. Use two columns for a bipartite network (node type A, node type B), or three for a weighted one-mode network (source, target, weight). The page checks the file at once: header row, bipartite or one-mode, number of nodes, and names that differ only by a trailing _.
  3. Run. Set the parameters and click Run. Correlation and odds-ratio methods take a significance level α (default 0.05) and a multiple-testing correction: Benjamini–Hochberg FDR (default), Bonferroni or none. Similarity and salience methods take a threshold between 0 and 1. Stricter settings keep fewer edges.
  4. Use the result. A projection gives one network per node set; download either, or choose Use for backbone to filter it straight away. A backbone shows the nodes, edges and components kept; Compare networks draws the input and the backbone side by side.

Input format

The header row is detected automatically; set First row is a header to Yes or No if your first row is misread. Node names are trimmed of surrounding spaces, and names that differ only by a trailing underscore (e.g. X_OF_BREAST and X_OF_BREAST_) are reported, since they are counted as different nodes.

Projections are treated as undirected (A–B is the same edge as B–A). Noise Corrected, Doubly Stochastic and Pólya filters offer a Directed option for directed networks. Hierarchical Backbone needs the original two-column bipartite file, not a projection. The Marginal Likelihood and Pólya filters model integer counts; non-integer weights are truncated or rounded, and a warning appears in the log.

Edge Betweenness

The edge betweenness of an edge is the number of shortest paths between node pairs that pass through it (Girvan & Newman, 2002), computed once for all edges with Brandes' algorithm (Brandes, 2001). Weights are similarities, so each weight w becomes a length 1/w. An edge is kept if its betweenness ≥ factor × mean betweenness.

Factor (default 1): larger values give sparser backbones. Use edge weights: No sets every length to 1. Sampled source nodes: 0 computes exact betweenness; a positive number estimates it from that many random source nodes, for very large networks. Output: source target weight edge_betweenness, sorted by betweenness.

Brandes, U. (2001). A faster algorithm for betweenness centrality. Journal of Mathematical Sociology, 25(2), 163–177. doi:10.1080/0022250X.2001.9990249
Girvan, M., & Newman, M. E. J. (2002). Community structure in social and biological networks. PNAS, 99(12), 7821–7826. doi:10.1073/pnas.122653799

Noise Corrected Filter

Computed exactly as in the authors' reference code (backboning.py). The weight of each edge is modelled as a binomial draw whose success probability has a Beta prior, fitted by the method of moments to the expected value NiNj/N². Each edge gets a score and its standard deviation, and is kept if score − δ × sd > 0. In an undirected network every edge counts in both directions, so N = 2 × total weight.

Threshold δ (default 3.09). Network type: Undirected (default) or Directed.

Coscia, M., & Neffke, F. M. H. (2017). Network backboning with noisy data. 2017 IEEE 33rd International Conference on Data Engineering (ICDE), 425–436. doi:10.1109/ICDE.2017.100

Doubly Stochastic Filter

The weight matrix (symmetric for an undirected network) plus 0.0001 in every cell, as in the reference code, is scaled with the Sinkhorn–Knopp algorithm until every row and column sums to 1. The constant makes the scaling exist: a sparse matrix often has none. Edges are then taken in decreasing order of their scaled value.

Stopping rule: Slater (default) adds edges until the backbone has as many connected components as the input (one for a connected network). On networks that are not connected this keeps most edges. Strict is a PRED-BiPN heuristic, not part of Slater's method: edges below the significance level α are skipped, it stops at the 20th percentile of the values, and every 1,000 edges it stops if the nodes reached form one component. α (default 0.05) is used by the Strict rule only. Network type: Undirected (default) or Directed.

Slater, P. B. (2009). A two-stage algorithm for extracting the multiscale backbone of complex weighted networks. PNAS, 106(26), E66. doi:10.1073/pnas.0904725106
Sinkhorn, R., & Knopp, P. (1967). Concerning nonnegative matrices and doubly stochastic matrices. Pacific Journal of Mathematics, 21(2), 343–348. doi:10.2140/pjm.1967.21.343

Modularity Filter

Algorithm 1 of Rajeh et al. (2022). The network is split into communities with the Louvain method (weighted, fixed seed). The modularity vitality of each node, α(v) = Q(G) − Q(G without v), is computed once on the original network with that partition, using weighted modularity. The backbone is the subgraph induced by the nodes with the largest |α(v)|. Nodes with equal |α| are taken in alphabetical order.

Share of nodes kept (default 0.30, rounded up). Louvain seed (default 42): the partition, and so the backbone, depends on it. Keep only largest component (default No): the article keeps the largest connected component of the backbone. Projections are often fragmented from the start, so this would drop every small component.

Rajeh, S., Savonnet, M., Leclercq, E., & Cherifi, H. (2022). Modularity-based backbone extraction in weighted complex networks. In Network Science (NetSci-X 2022), 67–79. Springer. doi:10.1007/978-3-030-97240-0_6

Data sources

The gene–disease association data used to validate the methods comes from:

Kontou, P. I., Pavlopoulou, A., Dimou, N. L., Pavlopoulos, G. A., & Bagos, P. G. (2016). Network analysis of genes and their association with diseases. Gene, 590(1), 68–78. doi:10.1016/j.gene.2016.05.044

The tool is not limited to this dataset: any bipartite or weighted edge list works.
