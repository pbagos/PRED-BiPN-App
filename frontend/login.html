Purpose & Scientific Background

PRED-BiPN (Bipartite Network Projection Tool) is a scientific software for network backbone extraction and analysis from bipartite networks. It was developed in the context of studying multifactorial diseases, where the rapid advancement of high-throughput techniques in Systems Biology has led to the accumulation of vast amounts of data, establishing network analysis as a crucial tool for understanding complex biological systems.

Methodology & Algorithms

The tool integrates 23 distinct backbone extraction methods, categorized into:

  • Statistical Methods: BiCM, SDSM, Polya Filter, Marginal Likelihood Filter, Disparity Filter, Noise Corrected Filter
  • Structural Methods: MST (Maximum Spanning Tree), Edge Betweenness, High Salience Skeleton, Global Threshold Filter
  • Hybrid Methods: Modularity Filter, Hierarchical Backbone, Locally Adaptive Network Sparsification (LANS), Doubly Stochastic Filter
  • Projection & Similarity Methods: Cosine Similarity, Adamic-Adar, Jaccard, Pearson/Spearman/Kendall Correlation, Resource Allocation

Data Sources

Method development and validation were performed using data from:

  • NHGRI-EBI GWAS Catalog: Genome-wide association studies with statistically significant associations (p-value < 5×10⁻⁸)
  • NCBI OMIM (Online Mendelian Inheritance in Man): Authoritative database for monogenic disorders with expert curation

The combination of these sources ensures comprehensive coverage of both multifactorial and monogenic diseases.

Theoretical Background

Bipartite networks B=(U,V,E) are characterized by:

  • Two distinct node sets U (e.g., genes) and V (e.g., diseases)
  • Edges connecting only nodes from different sets (E ⊆ U × V)
  • Support for weighted edge representation

One-mode projection transforms a bipartite network into a unipartite network, where two nodes are connected if they share a common neighbor in the original network.

Evaluation Metrics

The quality of the extracted backbone is evaluated through:

  • Density: ω = 2|E| / |V|(|V|-1)
  • Clustering Coefficient: C = (3 × number of triangles) / (number of triads)
  • Modularity: Q = (1/2m) Σ [A_ij - (k_i k_j)/(2m)] δ(c_i,c_j)
  • Diameter & Average Shortest Path Length
  • Centrality Measures: Degree, Betweenness, Eigenvector Centrality

⚕️ Biological Applications

PRED-BiPN enables:

  • Community Detection: Identification of functional gene groups collaborating in common biological pathways
  • Comorbidity Analysis: Recognition of diseases sharing common genetic backgrounds
  • Biomarker Discovery: Identification of critical hub nodes connecting seemingly unrelated pathologies
  • Hierarchical Knowledge Organization: Construction of DAGs (Directed Acyclic Graphs) for understanding general/specific relationships

📌 Key Findings

Comparative evaluation of methods revealed that:

  • Modularity Filter: Preserves dense community structures - ideal for studying comorbidities
  • Polya Filter & MST: Produce highly sparse, tree-like skeletons - reveal hierarchical relationships
  • Disparity Filter: Retains locally significant connections without undervaluing low-degree nodes
  • SDSM: Statistically rigorous but may lead to elongated communication paths

There is no single optimal method for all scenarios. The choice of algorithm must be tailored to the specific biological question, whether it aims to detect distinct functional modules or to identify the core pathways of biological information flow.
